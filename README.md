# 条文サーチ - 検証用ランディングページ

司法書士・予備試験向け「条文特化SRS」の需要検証ページです。

| ファイル | 中身 |
|---|---|
| `index.html` | LP本体（14KB）。デッキは埋め込まず、下のファイルへリンクする |
| `joubun-deck.apkg` | 配布中のAnkiデッキ。民法 第一編 総則（第1条〜第169条）122条・547枚 |
| `privacy.html` | iOSアプリのプライバシーポリシー |

デッキは `tools/build_apkg.py`（アプリ側リポジトリ）が `src/cards.json` から生成します。
手で編集しないこと。伏せ字を外すと原文と一字一句一致することを、書き出し前に全件検査しています。

不動産登記法はアプリの追加コンテンツ（買い切り）です。無料デッキには入れていません。

条文データの出典は e-Gov法令検索（デジタル庁）。
法令そのものは著作権法13条により著作権の目的となりません。
